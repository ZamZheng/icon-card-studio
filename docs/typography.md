# 母版字体分析与落地

依据用户在本聊天指定的蓝白母版。已实际读取 GitHub `ZamZheng/taste-skill` 的 `skills/taste-skill/SKILL.md`（tasteskill 2.5.1）及 `references/layout-v4.md`、`references/system.md` 的字体与层级说明。

Taste主要服务网页设计，不具备从图片确定字体文件的能力。本工程只借鉴一致的字体层级、可读性、真实字体加载和不缩字等适用原则；固定4:5卡片不套用网站导航、动效、随机配色、响应式网页及网站验收门槛。用户母版的多色品牌、标题倾斜和配色优先于网站默认规则。

## 观察与选型

| 角色 | 图片中可观察的特点 | 工具包选用 |
| --- | --- | --- |
| 主标题 | 中文重黑体，笔画粗、字面饱满，整体向右倾斜 | Noto Sans SC 900，72px，行高1.2，明确的几何倾斜-10° |
| 标题强调词 | 同一字形，亮蓝突出 | 同字体900，#0069ba |
| 栏目/期数 | 蓝色粗黑体，直立、紧凑 | Noto Sans SC 700，31px |
| 引导语 | 清晰的中等字重黑体，部分句子加粗 | Noto Sans SC 500 / 700，22px，1.55 |
| 知识小标题 | 深蓝粗黑体、比正文强 | Noto Sans SC 800，32px，1.4 |
| 知识正文 | 深蓝直立黑体，清楚紧凑 | Noto Sans SC 500，21px，1.5 |
| 01–04 | 白色、窄体、倾斜的阿拉伯数字 | Roboto Condensed 700 Italic，68px，真实斜体字形 |
| 提醒标题 | 白色粗黑体，倾斜 | Noto Sans SC 900，42px，明确的几何倾斜-8° |
| 提醒正文 | 白色普通黑体，两行 | Noto Sans SC 400，24px，1.45 |
| 社区落款 | 细于正文标题的直立黑体，蓝紫分色 | Noto Sans SC 400，28px |
| ICON Logo内文字 | 品牌资产本身的一部分 | 原文件，不以字体重新排版 |

以上是根据截图作出的视觉近似与工程标准，不是原字体识别结论。母版没有提供字体源文件，不能确认其原始商业字体名称、精确字重或像素字号。

Noto Sans SC没有中文斜体；中文标题使用已注明的CSS几何倾斜，浏览器的 `font-synthesis:none` 禁止未声明的伪粗体/伪斜体。数字使用字体包真实的Italic字形。所有角色使用实际存在的字重，本地WOFF2加载，CDP报告记录每个角色的实际字体；检测到系统回退则拒绝正式导出。

包版本：`@fontsource/noto-sans-sc@5.3.1`、`@fontsource/roboto-condensed@5.3.0`。两者授权均为SIL OFL 1.1。中文字体按实际文字的unicode-range嵌入所需子集，预览不用外部字体CDN。

本版首轮验收重点是：标题黑度及倾斜、数字宽度、小标题与正文的区分、手机缩放后的阅读清晰度。用户视觉确认后再将本母版登记为已验收版本。
