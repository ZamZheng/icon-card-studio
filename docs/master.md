# 固定蓝白母版 V1

设计画幅1080×1350，2倍输出2160×2700。配置来自用户确认的要素拆解；目前实现状态为 `visual-review-pending`，没有声称像素级复原或最终视觉通过。

## 固定组件

白与浅蓝背景、右侧弧线、底部四色波形；左上ICON原始Logo、竖分隔线、栏目和期数；左侧两行大标题及黄色弧形下划线；右上四色肖像框；蓝色斜切编号与黄色/绿色/紫色/绿色侧条；交替浅蓝知识行；蓝色提醒条和白色盾牌；底部双瓣标与完整社区落款。

背景与肖像框为依据母版建立的可复现CSS装饰，不冒充官方源矢量。ICON Logo始终使用用户原文件。固定社区双瓣标沿用旧工具稳定资产，来源见provenance。

各区域坐标、字号及颜色集中于 `config/master.v1.json`。这是工具维护配置，日常每期不改。HTML保留真实文字，固定区域内部自然换行；3条与4条使用各自的行高/间距预设。

## 每期内容

`issue`、`title`、`titleEmphasis`、`introduction`、`introductionEmphasis`、`points[]`、`reminder`、`reviewStatus`、`portrait`。未登记字段直接报错，不让AI在每期文案中悄悄覆盖字体/颜色/布局。

第一条知识的小标题宽度额外限制，以避开肖像底部。实际字形还会检测人物椭圆区冲突。超出容量优先在写稿阶段处理；经确认的原文进入排版后不得由程序改写。

## 软件版本保护

`config/package.lock.json`记录源代码、模板、固定配置、通用素材与npm lockfile的SHA-256。生产入口逐项核对。原始Logo作为私有品牌资产另有摘要，不通过软件摘要锁隐瞒素材变化。

运行报告记录软件版本、软件锁摘要、Logo/肖像摘要、本次字体文件摘要、浏览器/Node版本、内容与几何检查。发布新软件时修改版本、测试、重新登记摘要并打Git标签；日常生产使用固定标签。
